# Changelog

Все заметные изменения проекта описываются здесь. Формат — Keep a Changelog,
версии — семантические: мажорная растёт при несовместимости схемы базы,
минорная — при новых возможностях, патч — при исправлениях.

## [1.1.0] — 2026-09-18

### Добавлено

- **Импорт банковской выписки** (`/statement` или любой PDF-документ):
  - разбор PDF «Справка о движении средств» (`services/bank_statement.py`),
    1949 операций за 6 минут на реальной выписке Т-Банка;
  - золотая сверка: суммы операций сверяются с итогами «Расходы/Пополнения»
    из конца документа — расхождение показывается до импорта;
  - покупки и пополнения записываются с датой операции банка; переводы самому
    себе, снятия и комиссии в аналитику не попадают;
  - категоризация магазинов: правила по латинице и кириллице + порции по 10
    магазинов через локальную модель с нечётким сопоставлением ответа;
    кэш категорий между импортами — модель зовётся только для незнакомых;
  - дедупликация повторной загрузки по (дата, время, сумма, описание) за год;
  - отмена импорта одной кнопкой — удаляются только строки `source='bank'`;
  - кнопка «🏦 Выписка из банка» в меню отчётов с подсказкой.
- `add_transactions_bulk` и `delete_transactions_by_ids` в `database/db.py`;
  `add_transaction` принял параметр `created_at` для истории из выписки.
- pypdf в requirements.txt (раньше отсутствовал и тянулся бы только локально).

### Исправлено

- В `add_transactions_bulk` восстановлена логика закрытия долга при полном
  погашении (регрессия первой версии bulk-вставки).

## [1.0.0] — 2026-09-18

Первый релиз: полный функциональный контур от фото чека до панели управления.

### Запись и разбор

- Свободный ввод траты текстом («Заправка 2000»): ИИ определяет сумму, категорию,
  доход/платёж по кредиту; правила страхуют ответ без модели.
- Фото чека — двойное чтение: локальная vision-модель (`qwen3-vl`) + Tesseract.
  Победитель выбирается по арифметике (сумма позиций = итог кассы), потерянные
  строки добираются по остатку, второй проход включается при расхождении.
- Ручная правка позиций, спор с вердиктом, защита от повторной записи (окно дублей),
  пометка «кто читал» (правило / модель / человек).
- OCR срезает прилипшую шапку чека с первого товара («000 ПЯТЁРОЧКА КАССОВЫЙ ЧЕК…»).

### Аналитика и советы

- Разбор корзины: вердикт + причина + действие по каждому товару, суммы по группам,
  план на следующую закупку. Правила страхуют модель; одинаковые советы-затычки
  вычищаются; сохранённые вердикты сопоставляются позициям по названию.
- Личный список «не брать» и догадки модели отдельно: догадка не прячет товар без решения человека.
- Необязательные покупки: суммы и доли по вердиктам, динамика по неделям, эффект советов.
- Каталог «Мои цены»: обычная цена (медиана), где было дешевле, рост цен процентами.
- Список покупок по ритму чеков, «пора брать» и напоминания в момент записи.
- Недельный дайджест: цены, закупка, подписки, цель — одним экраном.
- Личная инфляция по своей корзине; прогноз продуктов по недельному темпу.

### Цели на месяц

- Товарная цель: одна привычка, измеримый шаг в разах или в деньгах (выбор человека),
  окно месяц с дня постановки, честный исход, история «сдержано N из M».
- Категорийная цель: «на сладкое» из мороженого, шоколада и печенья — две пометки
  «необязательно» на группу, матч по началу слова, состав на экране, покупка из
  группы сразу идёт в ход цели.
- Напоминание «⏪ Уже было» в момент покупки по истории вердиктов.

### Бюджет и настройки

- Лимиты у каждого свои, правка в самом боте; недельный лимит на продукты с прогрессом.
- Приветственная настройка нового пользователя; имя из Telegram вместо обезличенных обращений.
- Алерты при 90% лимита; «Статус сервисов» (Ollama, модели, Tesseract).

### Панель управления (Tkinter)

- База, чеки с вердиктами, каталог цен, аналитика (те же сервисы, что в боте),
  долги, настройки, CSV-выгрузка.

### Инфраструктура

- Три тестовых набора (смоук, интерфейсный через диспетчер, разбор чеков) —
  на каждый пуш в GitHub Actions; детерминированы без Ollama и личных фото.
- Всё локально: данные не покидают машину, Ollama опциональна (есть облако),
  Tesseract — второй независимый читатель.
