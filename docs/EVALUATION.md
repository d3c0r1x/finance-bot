# Проверка качества — Finance Bot

Три набора тестов, прогон без Ollama (обязательное условие CI), свои чеки в
тестах и инвентарь чеков для оценки качества чтения на всём наборе.

## Проверка

```bash
venv\Scripts\python.exe smoke_test.py       # модули, БД, аналитика, добор позиций, диаграммы, профиль
venv\Scripts\python.exe handlers_test.py    # реальные апдейты через диспетчер (настройка, меню, кнопки, чек)
venv\Scripts\python.exe receipt_test.py     # разбор чека по фото + продуктовый чек и разбор корзины
```
`handlers_test.py` подменяет сетевую сессию Telegram и проверяет, что у каждой кнопки есть обработчик и что разметка сообщений не ломается. `receipt_test.py` проверяет чек электроники, продуктовый чек с таблицей, узкий чек «кол-во × цена = итого» и разбор корзины.

Те же три набора гоняются автоматически в GitHub Actions на каждый пуш и пул-реквест (`.github/workflows/tests.yml`): свежий Python, системный Tesseract с русским и **без Ollama** — тесты обязаны проходить без модели, и это отдельная проверка, а не побочный эффект окружения. Локально эту же ситуацию можно повторить:

```bash
set OLLAMA_HOST=http://127.0.0.1:9 && python handlers_test.py
```

Шрифт для синтетических чеков ищется в `utils/fonts.py` (Windows, Linux, macOS), поэтому проверки не зависят от того, на какой ОС их запустили.

### Свои чеки в тестах

Фото чеков и реальные суммы — личные данные, поэтому в репозитории их нет: `receipt_samples.json` в `.gitignore`. Чтобы прогонять тесты на своих чеках, скопируй шаблон и заполни его:

```bash
copy receipt_samples.example.json receipt_samples.json
```

```json
{
  "grocery": {
    "photo": "data/receipts/мой-чек.png",
    "total": 1234.56,
    "is_grocery": true,
    "min_items": 10,
    "sum_tolerance": 120,
    "name_tokens": ["пиво"]
  }
}
```

Ключи образцов: `dns` (чек электроники), `grocery` (продуктовый с колонками), `narrow` (узкая таблица «кол-во × цена = итого»). Есть образец — проверка сверяет с ним; нет — печатает пропуск. Путь к фото можно передать и аргументом: `receipt_test.py путь\к\чеку.png` (тогда проверки с эталоном пропускаются).

### Инвентарь чеков

Когда чеков много и хочется видеть качество чтения на всём наборе, а не на одном удачном:

```bash
venv\Scripts\python.exe receipt_inventory.py            # только Tesseract, быстро
venv\Scripts\python.exe receipt_inventory.py --vision   # с моделью зрения (медленно)
venv\Scripts\python.exe receipt_inventory.py --strict   # выход 1 при грубых дефектах
```

Скрипт читает фото из `data/receipts`, ничего не пишет в базу и показывает, где разбор не сошёлся с итогом кассы.

В боте: **⚙️ Настройки → 🩺 Статус сервисов** — доступность Ollama, модель разбора трат, модель зрения для чеков и Tesseract.

## Автоматическая проверка на каждый пуш

`.github/workflows/tests.yml` запускает `smoke_test.py`, `handlers_test.py` и `receipt_test.py` в GitHub Actions на каждый пуш, пул-реквест и вручную. В CI нет ни Ollama, ни личных образцов чеков — так и задумано: если тест случайно зависит от модели или от фото владельца, он упадёт там, а не в тишине у тебя на машине.
